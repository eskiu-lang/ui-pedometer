## `<pedometer>`

`<pedometer>`: the steps the user walks, for apps on eskiu-lang/ui. use_steps counts them live
while a component is mounted; use_steps_between asks for the steps walked between two times,
the app open or not. CMPedometer on iOS; the step counter sensor on Android; nothing on the
web and the desktop. The platform asks the user for permission the first time.

Android keeps no history of steps: its sensor counts from the last boot. This package saves
a sample of that count each time it reads it (while use_steps or use_steps_between is mounted
and each time the app comes to the foreground), and answers a range from those samples, so
the steps between two times are known when the app was used before and after them with no
reboot in between. Steps walked across a reboot are counted from the reboot on.

### StepsStatus

```eskiu
enum StepsStatus { StepsWaiting, StepsReady, StepsDenied, StepsUnavailable }
```

Where a Steps count stands: waiting for the platform, a count is ready, the user denied
the permission, or there is no step counter (a simulator, the web, the desktop).

### Steps

```eskiu
struct Steps {
    int status;
    int64 steps;
    double distance = -1;
}
```

A count. `status` is a StepsStatus; `steps` is meaningful once it is StepsReady. Live counts
on iOS also have the distance walked in meters (-1 when the platform does not say).

### use_steps

```eskiu
Steps use_steps()
```

The steps walked since the calling scope mounted, live; the scope renders again with each
new count. The first use starts the platform's counting (and asks for permission), the last
one to unmount stops it; a later use counts from when it mounted only if it is the first.

### use_steps_between

```eskiu
Steps use_steps_between(int64 from_ms, int64 to_ms)
```

The steps walked between `from_ms` and `to_ms` (milliseconds since 1970), the app open or
not; the scope renders again when the answer comes. It is asked again when the range
changes and each time the app comes to the foreground. iOS answers for the last seven days.
